01 — Before RAG

We ask. The model answers — from memory only

"What's our password policy when creating a new user?"
"Typically, use a strong password with 8+ characters, a mix of letters and numbers…"
⚠ generic guess — never saw our internal docs

The model only knows what it was trained on. Our internal documents were never part of that.

01 — The Problem

Two tempting fixes — neither scales

🔁
Fine-tune the model Slow, costly to retrain — and stale again the moment a doc changes. ❌
📋
Paste the whole file in Blows past the context window, costs more, buries the real answer. ❌

02 — The Idea

Retrieve → Augment → Generate

🔎 Retrievefind the relevant facts
→
🧷 Augmenthand them to the model
→
✍️ Generateanswer using only that
The model isn't smarter — it just isn't guessing anymore.

04 — Ingestion · Zoom

Splitting with overlap, so nothing gets cut in half

The darker strips are shared between neighboring chunks — a 50-word overlap — so an idea split across the boundary is never lost.

04 — Ingestion · Zoom

Every chunk becomes a point on a map

Chunks with similar meaning land near each other. That's what makes searching by meaning possible.
